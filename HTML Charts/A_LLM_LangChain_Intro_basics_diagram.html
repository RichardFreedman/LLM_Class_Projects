1
API Management
Securely set your OpenAI API key using environment variables. Never paste the key directly in code.
import getpass, os
if not os.environ.get("OPENAI_API_KEY"):
  os.environ["OPENAI_API_KEY"] = getpass.getpass()
2
Model Selection
Choose which LLM to use. We use gpt-4o-mini for its balance of capability and low cost.
from langchain.chat_models import init_chat_model

llm = init_chat_model("gpt-4o-mini", model_provider="openai")
3
System + User Prompts
Define the LLM's role with a system prompt, then combine with user question using ChatPromptTemplate.
prompt = ChatPromptTemplate.from_messages([
  ("system", "You are a pirate..."),
  ("human", "{question}")
])
4
Return Results
Invoke the model with your prompt and get the response content back.
def ask_llm(question):
  message = prompt.invoke({"question": question})
  response = llm.invoke(message)
  return response.content
💡 Key Concept: The system prompt defines the LLM's "personality" or role, while the user prompt is the actual question. This separation allows you to create custom chat models for different purposes.
