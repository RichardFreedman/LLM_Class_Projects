Ingestion (Data → Vector Store)
Retrieval (Search)
Prompt Engineering
Generation (LLM)
1
Database Creation
Concert program data is wrapped in Document objects with metadata (Year, Ensemble), then converted to embeddings and stored in Chroma.
Document(page_content=..., metadata={Year, Ensemble})
2
Retrieval
User question is compared against vector store using similarity search to find top 10 most relevant documents.
vector_store.similarity_search(question, k=10)
3
Prompt Engineering
System prompt instructs LLM to use only provided context. User prompt combines retrieved context with the question.
prompt.invoke({context, question})
4
Generation & Output
LLM generates answer from context. Returns both the answer and source documents with metadata for verification.
result = {"answer": ..., "context": [...]}
