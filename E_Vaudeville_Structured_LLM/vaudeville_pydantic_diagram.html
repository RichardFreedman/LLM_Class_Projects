class Scene(BaseModel)
Used to split PDF into scenes:
act · scene · header
class MusicalMoment(BaseModel)
Extract musical data from each scene:
act · scene · number · characters · dramatic_situation · air_or_melodie · poetic_text · rhyme_scheme · stage_direction_or_cues
class VaudevillePlay(BaseModel)
Container for all musical moments:
musicalMoments: List[MusicalMoment]

📝 Sample Pydantic Field Descriptions (Prompts to the LLM)

characters
"the character or characters who are singing (or otherwise making music) within this specific musical moment"
list[str] = Field(description="the character or characters who are singing...")
poetic_text
"The text from the music number. Do not include stage directions, only the lyrics sung by the characters in this musical moment. Note that sometimes the text of a given number will be sung by different characters. Tell us which character sings which lines, but do not include the names of the characters in the transcribed poetry itself."
str = Field(description="The text from the music number...")
rhyme_scheme
"The rhyme scheme for the poetic text in the musical moment. For example, sentences that end in 'tree' 'be' 'why' and 'high' would have a rhyme scheme of AABB. If there are multiple parts with different rhyme schemes, please indicate which part has which scheme."
str = Field(description="The rhyme scheme for the poetic text...")
air_or_melodie
"The title of the 'air' or 'melodie' of which the musical moment is based. It will be labeled in the text as 'air' or 'melodie'."
str = Field(description="The title of the 'air' or 'melodie'...")
💡 Key Concept: Pydantic allows you to define exactly what fields the LLM should return, with descriptions that guide the model. The Field(description="...") parameter provides instructions to the LLM for each field.
