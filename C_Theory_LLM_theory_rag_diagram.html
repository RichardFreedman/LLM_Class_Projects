📤 Structured Output: Summary + Sample Documents

1. Summary Answer

Concise answer (max 3 sentences) with references to Source numbers and author names.
"According to Source 1 (Morley), good music requires..."

2. Source Grouping by Author

Results grouped by author for easy reading, with each group showing Source numbers, titles, dates, and page ranges.
=== Thomas Morley ===
[Source 1] 'A Plain and Easy...' (1601), pp. 45-47

3. Sample Document Content

Full text segments from retrieved documents showing the actual passages cited.
doc.page_content # Full text of segment

4. Metadata for Verification

Each source includes metadata: author, title, date, page_range for fact-checking.
doc.metadata = {author, title, date, page_range}
💡 Key Concept: The Theory RAG uses metadata filters after retrieval to refine results. This allows flexible exploration — first get semantically similar passages, then filter by century or author to focus the answer.
